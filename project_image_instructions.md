# Project Image Instructions

Use these instructions to generate the image assets for each project in the portfolio.

Each project needs two main image types:

1. Project card / cover image
2. Project logo / icon

An optional portrait-safe version can also be created if you want more flexibility later.

## 1. Project Card / Cover Image

**Purpose**

This image is used on the homepage project grid and as the large image at the top of the project detail modal.

It should give each project its own mood and visual identity while staying clean enough to work inside the current portfolio design.

**Format**

- Aspect ratio: `16:10`
- Recommended size: `1600 x 1000 px`
- File type: `.jpg` or `.png`
- Style: polished, modern, product-led, not too busy
- Avoid text inside the image
- Keep the main visual subject centered or slightly off-center
- Leave enough clean space so overlay tags remain readable
- Make sure it still works when darkened by a hover overlay

**Prompt Template**

```text
Create a modern portfolio project cover image for [project name].
It should be a polished 16:10 visual preview for a personal portfolio website.
No text, no logos, no UI labels.
Use a clean product/technology/startup aesthetic.
The image should have a clear focal point, balanced negative space, and work well with a dark hover overlay.
Aspect ratio 16:10, 1600x1000 px.
```

## 2. Detail Modal Logo / Icon

**Purpose**

This image is used inside the project detail modal as the small square brand mark that overlaps the cover image.

It should feel like a compact project identity: an app icon, simple logo, or abstract symbol.

**Format**

- Aspect ratio: `1:1`
- Recommended size: `512 x 512 px`
- File type: `.png`
- Transparent background or simple solid background preferred
- Must remain readable when displayed small
- Avoid detailed scenes
- Avoid long text
- A short initial, symbol, or abstract mark works best

**Prompt Template**

```text
Create a square app-style logo/icon for [project name].
It should work as a small project identity mark inside a portfolio case study modal.
Simple, distinctive, modern, and readable at small sizes.
Use minimal shapes and a clean color palette.
No long text, no detailed scene, no mockup.
Aspect ratio 1:1, 512x512 px.
```

## Recommended File Set

Create these files for each project:

```text
project-name-cover.jpg
project-name-logo.png
```

## Optional: Portrait-Safe Version

This is optional, but useful if the portfolio later uses taller project cards, social previews, or mobile-specific layouts.

**Purpose**

A taller version of the cover image that keeps the main visual subject readable in a vertical crop.

**Format**

- Aspect ratio: `4:5`
- Recommended size: `1200 x 1500 px`
- File type: `.jpg` or `.png`
- Same visual language as the main cover image
- Main subject centered vertically
- No text

**Prompt Template**

```text
Create a portrait-safe version of the project cover image for [project name].
It should match the same visual style as the main cover image.
No text, no logos, no UI labels.
The main visual subject should remain clear in a vertical crop.
Aspect ratio 4:5, 1200x1500 px.
```
